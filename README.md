## Migration of project repos to a new Github Organization account

Over the coming days I plan to migrate all the Asuswrt-Merlin related repositories to a new organization account named [@asuswrt-merlin](https://github.com/asuswrt-merlin).

If you cloned/checked out any of these repos, you will eventually need to change their remote URL.  Note that Github will still automatically redirect the old remotes to the new one, but it's best to update them sooner than later.

More information here: https://docs.github.com/en/get-started/getting-started-with-git/managing-remote-repositories
